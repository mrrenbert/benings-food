# Benings Food

Build a modern, responsive, and premium e-commerce frontend for "Benings Food" — a brand specializing in roasted tea products. The design should feel clean, minimal, professional, and luxurious, similar to high-end lifestyle tea brands. The website must be fully responsive: optimized for desktop, tablet, and mobile. On mobile, the desktop navigation must transform into a hamburger menu that opens a full-screen or slide-in menu with smooth animation.

Brand & Visual Style:
- Brand name: Benings Food
- Product category: Roasted Tea
- Visual direction: warm, natural, earthy, premium, clean, and modern
- Color palette: soft cream/beige background, deep green or tea-leaf accent, warm brown or roasted tones, elegant dark text
- Typography: elegant, readable sans-serif or modern serif for headings; clean sans-serif for body text
- Overall feel: high-end, trustworthy, lifestyle e-commerce

Required Pages / Sections:
1. Hero Section — full-width or split layout with large headline, short subheadline, CTA button to shop, background image or soft gradient, subtle entrance animation
2. Featured Products — grid of roasted tea products with image, name, short description, price, and "Add to Cart" / "View Details" button
3. Product Detail Page — large product image, product name, price, description, flavor/origin notes, quantity selector, add to cart button
4. About / Brand Story — short story about Benings Food and the roasted tea craft
5. Testimonials / Reviews — customer review cards with quotes and names
6. Newsletter / Contact — email signup form and simple contact info
7. Footer — links, social media icons, copyright

Responsiveness & Navigation:
- Sticky top navigation with logo on the left, menu links in the center/right, and cart icon
- On desktop: horizontal navigation menu
- On mobile/tablet: hamburger menu icon that opens a slide-in/full-screen menu with all navigation links
- Mobile layout must be thumb-friendly, readable, and visually balanced

UX & Animations:
- Smooth scroll and reveal animations on scroll (fade-up, fade-in)
- Hover effects on buttons and product cards
- 3D-style animations: subtle product card tilt, floating elements, or 3D product showcase effect
- Page transitions or micro-interactions to enhance premium feel
- Loading states should feel polished, not plain

E-Commerce Features:
- Product listing with add-to-cart functionality
- Shopping cart icon with item count badge
- Cart sidebar or modal showing added items, quantities, and total price
- Simple cart state management

Tech Stack:
- React + Vite + Tailwind CSS
- Use modern libraries like Framer Motion, GSAP, or equivalent for animations
- Component-based structure, clean file organization
- Fully responsive design using Tailwind breakpoints

Output:
- Generate a complete, working frontend project
- Make it visually stunning, not generic
- Ensure the design looks professional and ready for a real tea brand
- Comment non-obvious code sections briefly

Start by building the homepage with all sections, then connect product detail and cart functionality.
